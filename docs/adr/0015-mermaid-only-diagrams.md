# 0015. Diagrams in project documents use Mermaid only

* **Status:** Accepted
* **Date:** 2026-11-20
* **Deciders:** Hugh Kaznowski

## Context

An earlier draft used an ASCII diagram.

## Decision

Use Mermaid for every diagram in the design documents and ADRs. Do not use ASCII art.

## Consequences

A Mermaid viewer is needed to see the diagrams.

## Alternatives considered

* ASCII diagrams: rejected by author.
