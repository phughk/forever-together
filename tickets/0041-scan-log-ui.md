# 0041. Scan log: Settings card and export flow

* **Status:** open
* **Kind:** feature
* **Source:** ADR 0038, ADR 0029
* **ADRs:** [0038](../docs/adr/0038-scan-log-and-opt-in-export.md)
* **EGM:** none

## What

A Settings card shows how many characters and scans are logged, an Export button with the one-sentence consent line, a Clear button, and a link to the issue page. Desktop only; locked on a phone. Show, don't tell: no paragraphs.

## Done when

Stories for empty, some, full; typecheck and build-storybook pass; fits 1280x720 and 390x844.
