# 0007. Addon installer stage 2: native folder dialog and Linux detection

* **Status:** open
* **Kind:** feature
* **Source:** ADR 0028

## What

Add a server-side native folder dialog route, Linux detection of the AddOns folder, and first-run integration of the installer.

## Done when

Dialog route is loopback-only; Linux path detected; first-run step offers install when a folder is known.
