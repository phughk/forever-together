# 0013. Blocking, verification and trust networks

* **Status:** open
* **Kind:** idea
* **Source:** the tickets in `tickets/`; design doc Future Improvements
* **ADRs:** none
* **EGM:** none

## What

Block by IP, public key or character name; verification, cosignatures, an authoritative ban, temporary blocking, less gossip to bad actors, trust networks. Bans today are local for 60 s and never gossiped (ADR 0024).

## Done when

A design with threat model and an ADR before any code.
