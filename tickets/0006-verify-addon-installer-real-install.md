# 0006. Verify the addon installer on a real install

* **Status:** open
* **Kind:** verification
* **Priority:** P1
* **Source:** ADR 0028; docs/design-process/archive/addon_installer_concepts_brief.md
* **ADRs:** none
* **EGM:** [initial draft](../docs/egm/0006-verify-addon-installer-real-install/design_draft.md) (2026-11-22, unreviewed)

## What

Run the manual checklist: the Forever folder layout beyond the author's macOS machine, Windows and Linux default paths, game behaviour during an in-place swap, Windows file locking and admin rights, and whether the client ignores dot-prefixed folders such as `.ForeverTogether.new`.

## Done when

Each item answered in ADR 0028; Linux and Windows detection fixed if wrong.
