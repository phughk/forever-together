# 0012. Addon release flow and update tracking

* **Status:** open
* **Kind:** feature
* **Priority:** P1
* **Source:** the tickets in `tickets/`; ADR 0028
* **ADRs:** none
* **EGM:** [initial draft](../docs/egm/0012-addon-releases-and-updates/design_draft.md) (2026-11-22, unreviewed)

## What

The addon could be installed from a CurseForge link, and could use the GitHub API to track releases and updates. Players use release builds; the author bumps the `## Version:` in the TOC by hand. Decide the release artefacts and whether the app checks for updates.

## Done when

Release process written down; decision recorded in an ADR.
