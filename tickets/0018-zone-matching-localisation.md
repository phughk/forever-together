# 0018. Match zones on map IDs, not English names

* **Status:** open
* **Kind:** feature
* **Priority:** P2
* **Source:** design doc Open Questions
* **ADRs:** none

## What

Characters on other client languages get no same-zone ordering because the table holds English zone names.

## Done when

Table keyed by map ID.
